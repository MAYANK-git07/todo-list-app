# Todo List App

A simple and interactive Todo List App built using HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Manage daily tasks
- Clean and user-friendly interface
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open the application.
2. Enter a task.
3. Add it to your todo list.
4. Manage your tasks.
